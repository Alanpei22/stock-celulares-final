# Skills de Claude Code

Skills copiadas de [alirezarezvani/claude-skills](https://github.com/alirezarezvani/claude-skills) (commit `e4a1dc3`, licencia MIT, ver `LICENSE-claude-skills`).
Claude Code las carga automáticamente al trabajar en este repo.

| Skill | Para qué sirve en esta app |
|---|---|
| `code-reviewer` | Revisión de código y PRs (JS, Python como `convert_repairs.py`) |
| `senior-security` | Modelado de amenazas, búsqueda de secretos, revisar `firestore.rules` y `auth.js` |
| `focused-fix` | Arreglar un módulo roto completo (ej. "la caja no funciona") |
| `a11y-audit` | Accesibilidad y contraste de colores en las páginas HTML |
