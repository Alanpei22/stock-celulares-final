# Instagram skills

Copiadas de https://github.com/sergebulaev/instagram-skills (commit 550d3cf, licencia MIT, ver INSTAGRAM-SKILLS-LICENSE).

Claude Code las carga automáticamente al trabajar en este repo. Ejemplos:
- "Escribí un caption para un Reel sobre el iPhone 15 en stock"
- "Planificá una semana de posts de Instagram para el local"
- "Sacale el tono de IA a este caption"

Skills: ig-caption-writer, ig-carousel-planner, ig-hook-extractor, ig-hashtag-strategist,
ig-humanizer, ig-content-planner, ig-repurposer, ig-profile-optimizer, ig-audience-insights.

Opcional: `APIFY_TOKEN` (leer datos reales de Instagram) y `PUBLORA_API_KEY` (publicar). Sin ellas, las skills solo generan borradores.
